## First release

1. Check the [release status](../PROJECT_STATUS.md), confirm distribution rights for the included FXCRUX artwork, and review the files selected for the initial commit.
2. When ready to publish, import only this repository into the maintainer's GitHub account. Configure review and release controls as described in [Contributing](../CONTRIBUTING.md).
3. Let the first CI run finish. Start with a pre-release if legacy integrations or production deployment checks are still open. Describe the tested paths and credit accepted contributions in the release notes.
4. Link to the [local setup guide](../README.md#local-development) and [integration example](INTEGRATION.md) from the release notes.

## Announcement draft

FXCRUX License Engine is a self-hosted licensing server with an admin dashboard and a customer portal. Issue a key for your app, plugin, or CLI and validate it over HTTP. Your deployment keeps the licensing data and secrets under your control. See the Node.js example for a first integration. Contributions to the API, documentation, and product adapters are welcome.
